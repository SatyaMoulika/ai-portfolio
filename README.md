# Satya Moulika Pulla — AI Portfolio

React + TypeScript portfolio built with the repository's Porcelain & Azure design system, Tailwind CSS v4, and Vite.

## Run locally

Requires Node.js 20.19+ or 22.12+.

```sh
npm install
npm run dev
```

To create a production build:

```sh
npm run build
npm run preview
```

## Portfolio content

- Selected work: genre-conditioned screenplay generation, Enterprise Knowledge Assistant, polyp detection, AgentFlow, and an OpenAI conversational assistant.
- Experience and education draft based on the public LinkedIn profile. Employment dates and earlier schools are still to be confirmed.
- The avatar and two product screenshots are representative portfolio assets in `public/portfolio/`.

Project descriptions link to their source repositories. AgentFlow is private, so its source link requires repository access. No live application deployments are linked yet.

## Design system

The page uses the shared `src/design-system/` components and Porcelain & Azure tokens: Manrope UI typography, occasional Lora Italic accents, white surfaces, ink text, and Azure, Teal, and Violet accents.
